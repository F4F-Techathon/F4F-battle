# 设计规范 · 今晚吃啥 多智能体演播室

本规范约束 agent-studio 的全部界面，覆盖实时演播、角色资产库和系统架构三个视图。

视频项目里的角色本身（rig.js 的造型与配色）是作品资产，本规范**不改动**。需要统一的是界面外壳，以及所有资产的呈现方式。

## 1. 参考系统与借鉴点

| 参考 | 借鉴什么 | 落到本系统 |
|---|---|---|

| [Inworld](https://docs.inworld.ai/docs/tutorial-integrations/Unity/demos/sample-emotion) | 文本上方显示情绪标识；示例场景有一块监视器，实时显示服务器下发的情绪与手势 | 消息上方的表情头像；智能体坞实时显示每位角色当前的表情和手势 |
| [Convai State of Mind](https://convai.com/blog/convai-state-of-mind-how-emotions-drive-character-behavior) | 情绪按人设、对话和目标逐轮更新，再驱动声音与面部 | Jev 每轮重新决策，同一结果同时驱动表情动作和配音语气 |

## 2. 原则

1. **角色是主角，界面退后**：外壳用中性深色。角色色只用来标识身份，不当装饰。
2. **实时优先**：任何输入在 200 ms 内要有可见反馈。等待期用角色的预备动作（转头、提气、打字点）填补，不放转圈。
3. **一眼读懂**：表情一律用该角色对应表情的头像图标表示，少用文字。数据先给结论（首选 + 置信度），细节放进检视器。
4. **统一资产**：所有资产卡片使用同一底色、构图、光照和字体，2D 与 3D 并列时观感一致。
5. **直接播放，不平铺**：动画资产在卡片内直接循环播放，不再把每一帧排开展示。

| `--bg-2` | `#171922` | 卡片 |
| `--bg-3` | `#1F212B` | 输入框与悬停 |
| `--line` | `rgba(255,255,255,.07)` | 发丝分隔线 |
| `--line-2` | `rgba(255,255,255,.12)` | 强分隔线与描边 |

**角色身份色**（只用于界面标识，rig 内部配色不变）：

一种颜色只编码一种含义：角色色表示身份，情绪组色表示情绪类别，强调色表示交互焦点。

### 字体

- 界面文字：`Inter`, `Noto Sans SC`；字号 12 / 13 / 14 / 16 / 20 / 28，字重 400 / 500 / 600。
- 数字：`JetBrains Mono`，等宽数字。
- 舞台气泡与字幕：`Noto Sans SC` 500。不用卡通字体。
- 标题：`Noto Serif SC` 600。只用于视图标题和角色名，增加编辑感。

### 间距、圆角、阴影、动效

- **间距**：4 px 网格，取 4 / 8 / 12 / 16 / 24 / 32。
- **圆角**：胶囊 999，标签 6，输入与按钮 10，卡片 14，舞台 18。
- **阴影**：不用硬偏移阴影。卡片用顶部 1 px 内高光 `inset 0 1px 0 rgba(255,255,255,.04)` 加柔影 `0 8px 24px rgba(0,0,0,.35)`。
- **动效**：

  | 场景 | 时长与曲线 |
  |---|---|
  | 悬停 | 120 ms |
  | 状态切换 | 200 ms |
  | 进场 | 320 ms，`cubic-bezier(.22,1,.36,1)` |
  | 气泡 | 弹性进场 280 ms，淡出 200 ms |

  设置 `prefers-reduced-motion` 时，关闭抖动、粒子和镜头漂移。

## 4. 布局

- **实时演播**（主界面）：
  - 左侧是舞台（16:9）。舞台下方是智能体坞，横排四张实时卡片。
  - 右侧 420 px 是会话区：上方为实时会话流，下方固定撰写器。
  - 选中消息或智能体后，检视器从右侧滑出。
  - 没有时间轴，没有剪辑操作。
- **角色资产库**：
  - 左侧是分类栏，中间是标本网格，右侧是详情抽屉。
  - 顶部切换角色，三位角色同一套布局。
- **系统架构**：上方是实时管线图，下方是一致性检验。

## 5. 组件规范

**舞台**
- 布景：深色，带暗角、柔和顶光、地面反射。
- 聚光灯随发言人移动；非发言者亮度降到 70%。
- 名牌：玻璃质感细条。
- 指标：吃瓜值和心动指数做成直播式下三分之一条。

**气泡**
- 外观：92% 白，1 px 描边，圆角 22，左上角是角色色圆点加名字。
- 引用：放在正文上方，一行，次文字色，左侧 3 px 角色色竖线。
- 正文：逐字出现。
- 样式变体：
  - `shout`：2 px 角色色描边，倾斜 −1°。
  - `shaky`：高频抖动 2 px。
  - 粤语：正文下方附普通话释义。

**智能体卡（坞）**
- 内容：40 px 实时表情头像、名字、状态胶囊（待命 / 准备 / 发言中 / 反应中）、当前表情与手势、发言时的音量电平。
- 交互：点击设为发言人，双击打开检视器。

**消息卡**
- 主体：笑点时刻的表情头像，名字，语言标签，引用行，正文。
- 决策胶囊：表情头像 + 名称 + 置信度、手势、动作、语气。
- 旁听者反应：小头像，显示他们的反应表情。
- 状态行：Jev 耗时 · 首段音频耗时 · 时长。
- 操作：重播、检视、重新决策。

**标本卡（资产）**
- 外观：1:1 方形，统一背景（`#16171E` → `#0E0F14` 的径向渐变，上方一束柔光）。
- 构图：表情、口型、眼睛裁头部；手势和动作取全身。
- 标签：名称（中文，Serif）、id（等宽）、情绪组色点。
- 播放：进入视口后循环播放；点击打开详情，详情里有一个大号实时 rig，带播放 / 暂停 / 0.5× / 1× 控制。

**检视器（决策）**
- 每个问题一条分布条：单行堆叠，宽度按概率分配，首选段用强调色并标注。
- 置信度用环形表示。
- 三项评分用 4 级刻度。
- 原始请求和响应 JSON 默认折叠。

**生成的店主 agent**
- 形象：与原片同一画风，部件来自通用模板。
  - 主题色取 logo 主色。
  - 胸前有圆形胸牌，直接印店铺 logo。
  - 界面识别色是主题色提亮到能在深色界面上看清。
- 生成中：
  - 舞台上先站一个剪影：纯黑，外发光用主题色，呼吸起伏。
  - 头顶是步骤胶囊：形象 · 口音 · 组件 · 声音。进行中的一步用强调色，完成的打勾。
  - 「组件」步骤开始后剪影半显形；完成时亮相：发光闪一下，跳起挥手。
- 生成进度卡：
  - 舞台左下角玻璃卡，每步一行：序号或勾、步骤名、来源胶囊（Jev / 规则 + 耗时）、选中的结果。
  - 「组件」一行下面列出 20 个表情头像。
  - 完成 8 s 后淡出。
- 站位：
  - 多于 3 人时整体缩小，名牌只留名字；
  - 6 人以上，下三分之一条收紧间距；
  - 站位变化用 0.7 s 缓动滑动。

**「我」（台下顾客）**
- 头像：金色渐变圆形，中间是称呼的第一个字，与品牌标识同色系。
- 气泡：
  - 深色玻璃底，2 px 金色内描边，浅色正文，名字后标「台下」。
  - 从舞台底部、下三分之一条上方升起，尾巴朝下指向观众。

**多选引用**
- 撰写区的引用栏：
  - 标题写「同时回复 N 条 · M 人」，右侧「清空」；
  - 下面每条一行：角色色竖线、名字、原句、移除按钮。
- 线程里被选中的消息左侧加强调色内描边。
- 显示上限：
  - 消息卡和检视器最多显示 3 条引用，其余折叠为「还回复了 N 条」；
  - 舞台气泡也最多显示 3 条。

**资产总览**
- 顺序：通用模板 · 形象 → 通用模板 · 音色 → 原片角色 → 生成的 agent。
- 形象模板卡：
  - 竖版 4:5，按 女 / 男 两行，从矮到高排列。
  - 内容是全身动画（推销 + 竖大拇指来回播放）。
- 音色卡：播放模板、选口音、试听。外国口音第一次试听会提示正在生成提示音。
- 角色卡：64 px 头像，右下角压一枚 logo，下面是口音和音色标签。

## 6. 数据展示规则

- **结论先行**：卡片上只显示首选项与置信度，完整分布进入检视器。
- **表情图标化**：3 位角色 × 20 种表情预渲染成头像图标，在会话、坞、检视器、资产库里通用。
- **动画直接播放**：资产库和检视器都播放动画，不平铺帧。帧序列只在导出时生成（PNG 雪碧图）。
- **数字**：等宽数字。概率取整到百分比，小于 1% 显示 `<1%`。时间单位用 ms 或 s，保留 1–2 位小数。

## 7. 实时交互规范

**快捷键**

| 键 | 作用 |
|---|---|
| Enter | 发送 |
| Shift+Enter | 换行 |
| Alt+1…4 | 切换发言人 |
| Alt+↑ | 回复上一句 |
| Esc | 清除引用 |

**一句话的时间线**

导演一律用普通话写台词。打字时，改写预览会实时显示角色版本（四川话 / 粤语 / 法式口音 / 法语），同时预合成已经写完的分句。

| 时刻 | 发生什么 |
|---|---|
| 0 ms | 消息上屏，状态为「改写中」或「决策中」。发言人进入「准备」：视线转向被引用者，头顶气泡显示打字点。改写 LLM 与 Jev 同时开始，Jev 依据普通话原文决策 |
| Jev 返回（约 0.1–0.5 s） | 表情和手势立即生效；旁听者转头看向发言人 |
| 首段音频到达 | 开口，气泡逐字显示改写后的台词，粤语和法语附普通话原文；旁听者按台词进度在约 22% / 40% 处做出反应 |

**其他规则**
- **排队与插话**：默认排队。打开「插话」后，新发言会中断当前发言，被打断者露出惊讶表情。
- **兜底**：Jev 失败时用基线结果，并标注「基线」；配音失败时用估算口型，并标注「无配音」。
- **会话**：
  - 保存时命名；每句结束后自动保存，刷新后在空白会话区提供「恢复」和「恢复并播放」。
  - 自动播放按原顺序重演，使用录好的配音和当时的编排；播放中按钮变为停止，可以循环。

## 8. 可访问性

- 正文对比度不低于 4.5:1。
- 焦点环 2 px，使用强调色。
- 所有图标按钮都有 `title` 或 `aria-label`。
