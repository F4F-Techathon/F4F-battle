# 形成性研究问卷：「今晚吃啥」

对应形成性研究计划的阶段 A（问卷，n ≥ 100）。预计填写时间 6–8 分钟，共 7 个部分、约 50 题（含条件跳转，实际每人少于此数）。

## 使用说明

- **题型缩写**：单选 = 单选题；多选 = 多选题；排序 = 拖动排序；量表 = 7 点李克特量表（1 = 完全不同意，7 = 完全同意）；开放 = 文本填空。
- **选项顺序**：标注「随机」的题，选项顺序随机；「其他」「以上都没有」固定放最后。
- **跳转**：用 `→` 标注。
- **注意力检查**：D 部分和 E 部分各设 1 题，答错的问卷剔除。
- **措辞中立**：概念描述（E0）不使用「帮你解决选择困难」「智能推荐」等带评价的词，避免诱导。
- **先测后用**：正式发放前找 5 人试填，记录卡住的题和填写时长，再修订。
- **量表来源**：D 部分的选择困难题改编自最大化倾向和决策困难相关研究，E 部分的有用性、易用性、愉悦感题参考技术接受模型（TAM）的常见写法。正式引用前请对照原量表核对措辞。

## 附：分析要点

问卷回收后，按下表处理，对应研究问题 RQ1–RQ5：

| 研究问题 | 用到的题 | 分析方法 |
|---|---|---|
| RQ1 场景与痛点 | B3、B5、C2、C4、C6、C7 | 按同行人数分组，比较困难类型分布；多人场景是否在 C3 耗时、C7 不舒服、C6 不满上显著更高（卡方、Mann-Whitney U） |
| RQ2 偏好发现 | E3、E4、E5、C9 | 比较 E2–E5 的均值；开放题 C9、E15 做主题编码 |
| RQ3 时间与跳过 | E7、E12、E13 | E12 选「直接跳过」的比例；E7 与 E12 的交叉 |
| RQ4 商家端 | 本问卷不覆盖 | 由阶段 D 的商家访谈回答 |
| RQ5 赞助与付费 | F1–F5 | 频率分布；F2 与 D5、D6 的相关性；F5 的平均排名 |

补充分析：
- 用 D1–D6 的均值作为「选择困难倾向」，检验它与 E2、E5（使用意愿）的相关性，判断产品更适合哪一类用户。
- 按 B2（最常用方式）分组，比较 E5 的得分，判断替代对象是谁。
- 剔除标准：注意力检查答错；填写时长少于预测试中位数的三分之一；A4 选 0 次。
- 样本量太小时，不做推断性检验，只报告描述统计和效应方向。
