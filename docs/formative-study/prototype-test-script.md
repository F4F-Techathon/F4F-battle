# 原型测试脚本

对应形成性研究阶段 C：个人 12 人，多人 3–4 组（每组 3–4 人）。

## 一、研究问题与指标

| 问题 | 指标 | 来源 |
|---|---|---|
| 小剧场能否帮用户更快做决定 | 决策耗时 | 计时 |
| 能否帮用户发现事先没想到的条件 | 任务前后偏好清单的变化 | 偏好表 |
| 用户对结果是否更有信心 | 决策信心、满意度、预期后悔 | 任务后问卷 |
| 表演是否影响判断 | 最终选的是否为表演最强的角色；用户是否觉得被推销 | 记录、访谈 |
| 用户会不会跳过 | 跳过次数与时间点 | 记录 |
| 多人是否更容易达成一致 | 达成一致耗时；是否有人觉得被迫同意 | 记录、问卷 |

## 二、实验设计

组内对比，两个条件、两个场景，顺序平衡。

| 条件 | 内容 |
|---|---|
| **列表**（基线） | 三家餐馆的静态信息卡，内容和小剧场里角色说的事实一致 |
| **小剧场** | 三个角色轮流介绍并互相质疑，30–60 秒，可跳过，随后出汇总卡 |

| 场景 | 内容 |
|---|---|
| 场景 A | 工作日晚餐，需要聊天（见第四节数据 A） |
| 场景 B | 周末午餐，人较多（见第四节数据 B） |

四种顺序循环分配：
1. 列表 + 场景 A，再小剧场 + 场景 B
2. 列表 + 场景 B，再小剧场 + 场景 A
3. 小剧场 + 场景 A，再列表 + 场景 B
4. 小剧场 + 场景 B，再列表 + 场景 A

个人 12 人，每种顺序 3 人；多人每组按顺序循环。

## 三、准备清单

**人员**：主持 1 人、操作员 1 人（开演播室）、记录 1 人（计时）。

**设备**：
- 一台运行 `agent-studio` 的电脑，打开 `http://127.0.0.1:8770/`，已配置好 Jev 和 CosyVoice3（`STUDIO_NO_TTS=1` 时没有配音，只作备选）。
- 一台给参与者的屏幕，只显示舞台，隐藏检视器和事件流。
- 录屏和录音软件。
- 计时器（手机即可）。

**材料**：
- 知情同意书、偏好表（第五节）、任务后问卷（第六节）、访谈提纲（第七节）。
- 列表条件的静态信息卡：每个场景一页，三家餐馆并排，字段与第四节数据一致，不加任何评价性文字。
- 三位角色的会话文件（见下）。

**会话文件**：
1. 按第四节的数据，为每个场景在演播室里预先写好三位角色的开场推介和一到两轮质疑，保存为会话。
2. 台词里涉及的事实只能来自第四节数据，不引入额外信息。
3. 两个场景的台词长度、质疑次数、角色顺序要匹配，总时长都控制在 45 秒上下。
4. 保存后在实机上用「自动播放」试一次，确认配音和口型正常。

**重要提示**：本测试使用的餐馆、价格、排队时间全部是虚构演示数据。参与者必须在开场被告知这一点，结果页也要标注「虚构数据」。

## 四、场景数据

两个场景难度相当：各有三家餐馆，没有一家全面占优；各有一个「隐藏维度」，大多数人事先不会写进偏好，但会影响满意度。

### 场景 A：工作日晚餐，两到三个人，想好好聊天

人均预算上限约 150 元，希望步行 15 分钟内。

| | 川味小馆（老板娘） | 粤式茶餐（陈老板） | 法式小馆（主厨） |
|---|---|---|---|
| 人均 | 90 元 | 130 元 | 220 元 |
| 步行 | 6 分钟 | 12 分钟 | 15 分钟 |
| 高峰排队 | 约 40 分钟 | 约 15 分钟 | 免排队，需订座 |
| 环境噪音 | 很吵（开放大厅） | 中等 | 安静（有包厢） |
| 招牌 | 水煮鱼、毛血旺 | 烧鹅、煲仔饭 | 油封鸭、牛排 |
| 上菜 | 快 | 中等 | 慢（约 40 分钟全部上齐） |

**隐藏维度**：噪音 / 能否聊天。**典型冲突**：川味小馆最便宜最近，但吵、要排队；法式安静，但贵、慢。

### 场景 B：周末午餐，四到五个人，有人不吃辣

人均预算上限约 100 元，可以乘车 20 分钟内。

| | 川味小馆 | 粤式茶餐 | 法式小馆 |
|---|---|---|---|
| 人均 | 80 元 | 95 元 | 160 元 |
| 路程 | 乘车 10 分钟 | 乘车 20 分钟 | 乘车 15 分钟 |
| 高峰排队 | 约 60 分钟 | 约 30 分钟 | 免排队，需提前一天订座 |
| 不吃辣的菜 | 少（约三分之一） | 多 | 多 |
| 包间与大桌 | 无，最多 4 人一桌 | 有圆桌，可坐 10 人 | 无，最多 6 人 |
| 招牌 | 火锅、冒菜 | 早茶点心 | 套餐 |

**隐藏维度**：能否坐在同一桌 / 不吃辣的人是否有菜可吃。**典型冲突**：川味最便宜，但分桌坐、有人没菜吃；粤式合适但远、要排队；法式贵。

## 五、偏好表（任务前后各填一次）

任务前（口头说明后填写）：

> 假设今晚要选一家餐馆。请写出你选餐馆时最看重的 3 个条件，并按重要性排序。

| 排序 | 条件 | 你为什么看重它 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

任务后：

> 现在你已经做出了选择。请再写一次：**你选这家餐馆时，最看重的是哪 3 个条件？**（不用和刚才一样）

| 排序 | 条件 | 你为什么看重它 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

追加题：「做完选择后，有没有哪个条件是你一开始没想到、但现在觉得重要的？是哪个？是在哪个环节想到的？」

**编码方式**：两名编码员独立判断「任务后清单是否出现任务前清单没有的条件」，不一致处讨论后确定。统计新增条件的数量，以及是否包含该场景的隐藏维度。

## 六、任务后问卷（每个条件后各填一次）

量表为 1–7（1 = 完全不同意，7 = 完全同意）：

1. 我对自己选出的餐馆有信心。
2. 我对这次选择过程感到满意。
3. 我担心这个选择以后会让我后悔。（反向计分）
4. 这个过程让我发现了自己之前没想到的条件。
5. 我觉得所得到的信息足够做决定。
6. 我觉得这个过程花的时间合适。
7. 我觉得这个过程有趣。
8. 我觉得有人在影响我的选择（不是我自己选的）。（反向计分）
9. 我相信刚才看到的餐馆信息。

多人组额外：

10. 我觉得我的想法被听到了。
11. 我觉得最后的决定是大家都能接受的。
12. 有人对结果不满意，但没有说出来。（反向计分，由每位成员各自填）

## 七、测试流程

### 个人测试（约 40 分钟）

| 时间 | 环节 | 内容 |
|---|---|---|
| 0–5 分钟 | 开场 | 同意书、说明虚构数据、录屏录音 |
| 5–8 分钟 | 偏好表（任务前） | 填第一份偏好表 |
| 8–17 分钟 | 条件一 | 完成选餐任务，边做边说想法 |
| 17–22 分钟 | 问卷与偏好表（任务后） | 填任务后偏好表和问卷 |
| 22–31 分钟 | 条件二 | 完成第二个场景的选餐任务 |
| 31–35 分钟 | 问卷与偏好表（任务后） | 同上 |
| 35–40 分钟 | 访谈 | 见下方提纲 |

### 多人测试（约 50 分钟）

流程同上，但：
- 参与者自行组成一组，事先要求他们是熟悉的人，且平时一起吃饭。
- 偏好表和问卷每人单独填，互不查看。
- 每个条件下不限制交流，允许争论，最长 8 分钟，超时则让他们用手头的方法决定。
- 偏好表只在任务前和每个任务后各填一次，每人填自己的。

### 主持说话稿

开场（念）：
> 谢谢你来。今天我们想测试一个选餐馆的方法，不是测试你。你做什么都对。接下来的餐馆、价格、排队时间**全部是虚构的**，只用来做练习。你可以随时停下。可以开始录屏录音吗？

任务说明（列表条件）：
> 假设你在这个情境里（读场景描述）。下面三家餐馆的信息都在这张卡上。请你选一家，选好后告诉我。过程中想到什么，请直接说出来。

任务说明（小剧场条件）：
> 假设你在这个情境里（读场景描述）。屏幕上会有三位餐馆代表轮流介绍。你可以随时跳过，随时插话说出你的想法。看完后，请你选一家，选好后告诉我。过程中想到什么，请直接说出来。

不要说：「看角色吵架会帮你更快决定」「这是我们做的新功能」。

### 操作员与参与者插话

- 小剧场条件下，参与者可以在任何时间用口头补充条件，例如「我不太想排队」。
- 操作员在演播室里以「我」的身份输入这句话，让角色回应（Wizard-of-Oz）。
- 操作员只转述原话，不做改写，也不加提示。
- 如果参与者想跳过，直接跳到汇总卡，并记录跳过的时间。

### 访谈提纲（测试后 5 分钟）

1. 两种方式比较，你更愿意用哪个？为什么？
2. 小剧场里，有没有哪句话改变了你的想法？是哪一句？
3. 有没有哪里你想直接跳过？
4. 你觉得角色的表演有没有影响你的选择？比如你选了表演更夸张的那位。
5. 你觉得这些信息可信吗？为什么？
6. 如果这是真实的应用，你什么时候会用，什么时候不会？
7. （多人）你觉得这个方式对你们几个的决定有帮助吗？有没有哪一刻觉得别扭？

## 八、记录表

每次任务一行：

| 字段 | 说明 |
|---|---|
| 参与者编号 / 组号 | P01、G01 |
| 顺序编号 | 1–4 |
| 条件 | 列表 / 小剧场 |
| 场景 | A / B |
| 开始、结束时间 | 以口头选定为结束 |
| 决策耗时 | 秒 |
| 是否跳过、跳过时间点 | 小剧场条件 |
| 插话次数与内容 | 小剧场条件 |
| 最终选择 | 川味 / 粤式 / 法式 |
| 选的是否为表演最强的角色 | 由两名观察者判断（见下） |
| 新增条件数 | 来自偏好表编码 |
| 是否提到隐藏维度 | 是 / 否，何时提到 |
| 问卷得分 | 第六节各题 |
| 困惑与问题 | 观察到的卡点 |

「表演最强」判定：由观察者在演出前，用数字 1–3 给三位角色的表演强度（动作幅度、声音大小、说话时长）排序，再看参与者最终选了哪位。若三位角色的强度排序在两个场景里不平衡，需要在分析时说明。

## 九、分析

- **耗时、问卷得分**：个人数据用配对检验（Wilcoxon 符号秩检验），样本小时只报告描述统计和效应方向。
- **新增条件**：比较两个条件下新增条件数和隐藏维度被提到的比例。
- **多人**：只做描述统计和逐组案例描述，不做推断检验。
- **访谈**：与问卷结果一起做主题归纳，重点看「改变想法的那句话」和「想跳过的环节」。
- **判断标准**（事先设定，与研究计划一致）：
  - 小剧场的耗时不超过列表的 1.5 倍；
  - 信心或满意度高于列表；
  - 至少三分之一的参与者提到「我没想到自己在意这点」；
  - 跳过率不超过 50%。

## 十、风险与处理

| 风险 | 处理 |
|---|---|
| 新鲜感偏差 | 测试一周后回访 3–5 人，问是否还愿意用 |
| 台词质量影响结果 | 两个场景的台词长度、质疑次数匹配，由两人审核事实 |
| 配音或口型出错 | 测试前整套自动播放一遍；备用方案是无配音版 |
| 参与者受操作员影响 | 操作员不与参与者交谈，也不看参与者的偏好表 |
| 参与者认为商家在花钱做推荐 | 开场说明虚构数据；汇总卡标注「演示数据」 |
| 样本偏向校内学生 | 报告里写明，结论只作形成性参考 |
